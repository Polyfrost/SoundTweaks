# SoundTweaks

[![Modrinth downloads](https://img.shields.io/modrinth/dt/7hJZhArg?style=flat&logo=modrinth&label=Modrinth&color=1bd96a)](https://modrinth.com/mod/soundtweaks)
[![CurseForge downloads](https://img.shields.io/curseforge/dt/1740840?style=flat&logo=curseforge&label=CurseForge&color=f16436)](https://www.curseforge.com/minecraft/mc-mods/soundtweaks)

SoundTweaks gives every single sound in the game its own volume slider.

- Mute a sound or boost it up to 200%
- Covers sounds added by resource packs and other mods too
- Sounds are sorted into groups like Entity and Block
- "Remove Volume Cap" lets boosted sounds go past Minecraft's usual maximum

## Supported versions

- Minecraft 1.8.9 on Ornithe.
- Minecraft 1.21.1-26.3 on Fabric.

SoundTweaks needs [OneConfig](https://modrinth.com/mod/oneconfig) and Fabric Language Kotlin. The Fabric builds also need Fabric API.
